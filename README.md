# Sahyadri Samrakshane 🌿

Sahyadri Samrakshane is an Android application designed to support environmental protection, ecological monitoring, and community-based forest alert reporting in the Western Ghats region.

Built using modern Android development technologies such as Kotlin, Jetpack Compose, Firebase, Room Database, WorkManager, and Hilt Dependency Injection, the app provides a clean and scalable offline-first architecture for real-world ecological reporting systems.

## ✨ Features

* 📍 Real-time GPS location tracking
* 📷 Camera integration for field evidence capture
* 🌲 Forest fire and ecological alert reporting
* 🔄 Offline-first data storage with automatic sync
* 🔔 Firebase Cloud Messaging notifications
* 🗺️ Google Maps integration support
* 🎨 Modern Jetpack Compose UI
* ⚡ WorkManager background synchronization
* 🧩 Hilt Dependency Injection
* 💾 Room Database local persistence

## 🛠️ Tech Stack

* Kotlin 2.0
* Jetpack Compose
* Material 3
* Firebase
* Room Database
* Hilt
* WorkManager
* Navigation Compose
* CameraX
* Google Maps SDK

## 🚀 Setup Instructions

1. Clone the repository
2. Open project in Android Studio
3. Add your `google-services.json`
4. Add Google Maps API key in `local.properties`
5. Sync Gradle
6. Run the app on an Android device

## 🔐 Security Note

Sensitive files such as:

* `google-services.json`
* keystore files
* API keys

are intentionally excluded from the repository.
